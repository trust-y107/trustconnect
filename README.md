# TrustConnect コーポレートサイト

HP案に沿って制作した、TrustConnect株式会社のコーポレートサイトです。

## ページ構成

| ファイル | ページ |
|----------|--------|
| `index.html` | HOME（トップページ） |
| `about.html` | 私たちについて（代表メッセージ・経営方針・会社概要・沿革） |
| `business.html` | 事業内容（通信サービス販売／人材派遣） |
| `vision.html` | 私たちの想い（差別化ページ） |
| `contact.html` | お問い合わせ |
| `css/style.css` | デザイン（配色・フォント・レイアウト） |
| `js/main.js` | メニュー開閉・スクロール演出・フォーム動作 |

## 見かた

`index.html` をダブルクリックすると、ブラウザでサイトが開きます。
ページ上部のメニューから各ページに移動できます。

## デザイン仕様（案どおり）

- **コンセプト**：信頼でつなぐ、わたしたちの仕事。
- **配色**：ロゴに合わせた信頼感ブルー＋安心感・少しの幸福感（差し色のオレンジ）
- **フォント**：見出し＝Noto Serif JP（明朝体）／本文・UI＝Inter（ゴシック体）

## トップの写真について

トップページのタイトル横の写真は、いただいた集合写真を **背景切り抜き（人物だけ）** に加工して使っています。

- `images/team_cutout_web.png` … 実際に表示している切り抜き画像
- `images/DSC08280.jpg` … 加工前の元写真（差し替え・再加工用に保管）
- `bgprocess.swift` … 背景の切り抜き／ぼかしを行うスクリプト

写真を別のものに変えたい場合は、新しい写真で `swift bgprocess.swift <写真のパス>` を実行すると、切り抜き版（`team_cutout.png`）とぼかし版（`team_blur.png`）が作れます。お気軽にお声がけください。

## 公開前に差し替えていただきたい箇所

実際の情報に置き換えてご利用ください（`※`印のついた箇所が目印です）。

- **会社概要**（`about.html`）：設立年・所在地・代表者名・資本金・派遣事業許可番号
- **代表者名／代表者写真**（`about.html`）：「山田 太郎」と写真エリア
- **沿革**（`about.html`）：年号と内容
- **電話番号・メールアドレス**（`contact.html`）
- **お問い合わせフォーム**：現在は「デモ送信」です。実際にメールを受け取るには、フォーム送信サービス（例：Googleフォーム、Formspree など）との連携が別途必要です。

何か調整したい点があれば、お気軽にお知らせください。
